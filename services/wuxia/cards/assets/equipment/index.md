# 现有兵器原画

当前运行目录的同名兵器原画，用于侠客页的大幅装备展示。按名称精确绑定，不将新版图鉴的不同器物套用为旧装备。此目录是旧物件身份的展示素材，不作为新装备制作规范。

- `manifest.json` — 实际兵器名称到 WebP 文件的映射，由卡片渲染器嵌入并加载。
- `weapon-*-cutout.webp` — 使用 imagegen 提取的同名器物透明主体，供卡片共享背景合成。
- [透明主体提示词](cutout-prompts.json) — 输入器物、生成路径及提示词记录。
- `weapon-数字.webp` — 从 WebUI 旧装备目录复制的对应独立原画，来源与生成提示词见[原素材索引](../../../../../webui/public/equipment/index.md)。

新的兵器及护具饰品按[正式制作规范](../../../../../webui/public/equipment-v2/production-rules.md)制作。将新图鉴接入游戏时，应同步物件定义、名称、素材映射及数值，不能只替换贴图。
