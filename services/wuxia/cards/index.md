# 武侠本地卡片

- `render.go` — 静态图集、字体、PNG编码和纯文字回执的公共入口。
- `theme.go` — 靛蓝／暖白／朱砂配色、字体层级、线条、资源标题与命令牌。
- `skin.go` — 九宫格银白边框、纹样标题签、属性徽记与装备格。
- `display.go` — 内嵌标题字形、正文中文字体回退与标题排版。
- `profile.go` — 属性、人物与行囊分区、已装备物品、兵刃收藏与每日进度。
- `report.go` — 单次宽卡、双列／三列历练卡片、奖励和掉落结算。
- `draw_card.go` — 寻宝物品展示、费用和背包／学艺入口。
- `casino_card.go` — 骰面、押注结果与银两净收益卡片。
- `skill_art.go` — 加载、缓存按技能 ID 绑定的武学插画。
- `skill_icons.go` — 按已保存武技/心法身份绘制专属图标，主页及战报共用。
- `battle_card.go` — 双方角色与兵器、气血变化和完整交锋记录。
- `render_test.go` — PNG输出、取消行为、透明素材与离线预览；设置 `YUELING_WUXIA_PREVIEW_DIR` 可保存预览。
- [静态资源](assets/index.md) — 场景、职业形象、稳定ID区域映射与制作提示词。

名称、属性、装备、逐招结果和命令取自实际角色数据。静态美术在构建前制作，运行时仅使用Go本地合成，不调用图像模型。角色形象可以独立于职业选择。

字体从项目 `data/fonts` 和系统中文字体目录查找。每次绘制使用独立字体Face，避免并发共享绘制状态。游戏回执先持久化再呈现，图片排版失败不会重新计算奖励。预览测试使用仓库实际字体目录，以便检查部署所用字体的排版。

- `candidate_preview_test.go` — 用候选目录生成各职业真实配装、历练、寻宝与切磋页面。

- `list_card.go` — 背包、武学、榜单与选项的图文列表分页，以及规则提示手帖。
- `list_card_test.go` — 列表分页、空状态、取消绘制与本地指引预览。

- `female_art_test.go` — 女性立绘/战败图资源、透明角及正常/战败头像切换验证。
