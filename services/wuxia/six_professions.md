# 六职业候选：兵器、武技与成长

## 使用边界

可执行数据在 `internal/content/six_professions.json`，版本 `wuxia-six-candidate-5`。使用与正式玩法相同的Catalog.View与Duel进行模拟，未替换Default目录、未部署。现有三职业ID保留；问剑、狂刀、镇岳为新显示名，新职业是幽影、千蛊、弦歌。女性外观不参与属性计算，但性别命令、男女立绘尚未接入。

六职业均有五档兵器和职业武技，护具饰品及五档心法通用。兵器没有人物等级门槛，职业类别限制保留。兵器自身强化不是角色等级，当前矩阵固定未强化；本轮不宣称强化与全部分支已经平衡。候选目录33件兵器及36门武技/心法原画已齐，大小图共用同一原画。六职业均有候选立绘，QQ战报展示追击、毒与吸血。性别切换、正式目录迁移和真实群聊验收仍待接入，不能直接启用候选目录。

## 基础值与成长

下表为裸身1级值及每级固定增长，依次为气血/攻击/防御/身法。等级上限10，经验门槛沿用 `30×等级×(等级−1)`。练武和配装在成长后另计，不把品质换算成人物等级。

|职业|1级基础|每级增长|职业固有加成|
|---|---|---|---|
|问剑|950/155/13/23|115/30/2/3|暴击+10个百分点、闪避+5个百分点、暴伤+10个百分点|
|狂刀|1050/160/14/17|135/35/2/2|穿透+16个百分点|
|镇岳|1100/135/17/19|150/25/2/2|格挡+14个百分点|
|幽影|950/140/12/28|125/30/2/3|连击+20个百分点|
|千蛊|1025/140/14/19|135/30/2/2|附毒+20个百分点|
|弦歌|1000/145/14/20|130/30/2/2|吸血+20个百分点|

概率与倍率不是同一种收益。暴伤基础175%，词条+10个百分点后为185%，不是乘1.10；暴击基础10%、招架基础8%，闪避基础14%另加身法贡献。幽影追击只追加一次普攻，不能复制大招；千蛊毒伤延后结算，可能来不及兑现；弦歌只按实际伤害吸血，被压制时续航随之降低。具体上限及事件顺序见[战斗契约](combat.md)。

镇岳的普攻成长不能为了大招而被压低，否则未学武技的角色会异常弱；因此攻击逐级+5，同时降低拳系武技段倍率。狂刀身法逐级+2，仍慢于幽影，但不会到后期完全追不上。候选调整不回写旧目录。

## 兵器与武技

兵器类别采用固定品级预算100/60/30/10/2；同职业同品级有多件时共享该档预算，避免增加一把传世就提高整个传世概率。武器类别占寻宝35%，最高品约占全部寻宝0.347%；秘籍类别20%，职业传世与心法传世合计约占全部寻宝0.198%。整数权重分配会产生极小舍入误差。

五档为不同器型与文案，不用换色复制。所有新器物无实景背景；高阶描述加深器物来历和意象，传世用两句七字诗。数值文本由配置生成，不能把描述当机制解析。完整数据与成长可在本地 `http://127.0.0.1:19083/wuxia-preview.html#professions` 按职业查看。

所有候选武技从首次自身出手起独立判定，没有起手门槛、保底、冷却或每场次数上限；失败则普攻，连续成功可连续施展。连击追加段不额外掷一次武技。心法的首击、首次武技与第三次行动回复规则保留。兵器affinity匹配时只有武技段增伤10%，追加普攻不继承该增伤。高品质的收益通过整场对局验证，不能只盯着面板倍率。

## 验证与复现

原始结果：[六职业对战报告](six_professions_balance.json)。基础矩阵与另一组种子复测各900格、每格3000场，合计540万场；六套通用配装各270万场，合计2160万场。覆盖1/5/10级、五档同品兵器、有无同档武技与心法，六职业15组配对并交换左右。

最终八组配对胜率31.7%～68.5%，无每个对手均60%以上的职业。种子1000000组在本轮发现越界后参与了调整，因此属于回归复测，不能声称从未用于调参的盲测。3000场仍有抽样误差，临近30%的组合需持续观察。旧版代表配装和品质报告不用于证明本轮参数。

内容测试验证职业品级完整、初始气血范围、传世攻击较名器至少提升45%、穿戴与奖池资格、预览同源。收益测试覆盖饰品对正收益、负面事件与高人指点的边界。

```sh
WUXIA_SIX_REPORT=/tmp/six-training.json go test ./services/wuxia -run '^TestSixProfession' -count=1
WUXIA_SIX_REPORT=/tmp/six-holdout.json WUXIA_HOLDOUT=1 go test ./services/wuxia -run '^TestSixProfessionMatrix$' -count=1
WUXIA_CANDIDATE=1 go test ./services/wuxia -run 'TestMartial(QualityAudit|EventsConserve)' -count=1 -v
WUXIA_CANDIDATE=internal/content/six_professions.json WUXIA_MARTIAL_REPORT=/tmp/six-armored.json WUXIA_HOLDOUT=1 go test ./services/wuxia -run '^TestBurstCrossProfessionAudit$' -count=1
```

没有穷举全部兵器分支、心法交叉配装、强化、第二门传世在所有跨职业组合中的表现，也未完成新职业PVE专项验证。报告只证明上述条件初步通过，不能写成全面平衡。正式开启前还需完成旧职业名兼容与性别交互，然后做真实指令验收。

## 六职业图鉴与通用装备扩展

统一预览的装备、武学、职业成长三个标签读取同一候选目录。已有认可兵器原画按原名对齐候选基准兵器，稳定ID不改；新增短刃、蛊器、古琴各五档。未绘原画的条目用文字占位明确标注，不能复用其他武器或技能图误导。旧角色兼容用的兵器变体保留。

60件通用护具饰品均写入候选数值与银两奖池：各槽五档，每档六件，全职业1级可用。已有同名条目复用稳定ID，其他旧装备保留兼容。各槽内部按100/60/30/10/2分配品级权重，同档多件共享预算，不靠扩充条目稀释整个品级。武器35%/护具25%/饰品20%/秘籍20%类别预算不变。

|路线|护具收益|饰品收益|取舍|
|---|---|---|---|
|轻灵追击|身法、闪避、少量连击|连击、暴击、身法|气血防御较低；追击不复制大招|
|稳守破阵|气血、防御、格挡|攻击、穿透、暴伤|没有吸血和附毒，不兼得最高机动|
|调息蚀伤|适中气血防御、附毒、少量吸血|附毒、吸血、少量气血|需要先打出有效伤害，毒延后兑现|

六套路线各覆盖900格×3000场，详见当前报告的universal字段及其seed_start，不沿用旧版胜率。同槽同品不同路线可混搭，但本报告没有穷举所有跨路线混搭，不能据此称其全面平衡。

```sh
WUXIA_UNIVERSAL=0 WUXIA_HOLDOUT=1 WUXIA_SIX_REPORT=/tmp/six-light.json go test ./services/wuxia -run '^TestSixProfessionMatrix$' -count=1
# 将0改成1、2分别验证另外两套；报告保存universal_set以标明实际配装。
go test ./services/wuxia -run '^TestUniversalEquipmentTraitsAndAccess$' -count=1
```

## 气血尺度、武器品质与历练饰品

初始裸身气血950～1100；气血、攻击及其固定装备值扩大五倍。防御采用80/(80+防御)减伤曲线，因此防御、身法、概率、心法百分比不等比例扩大，避免改变减伤与出手节奏。高品级兵器在尺度换算外增加预算：上品、名器、传世拉开攻击，刀与拳按对局重新校正。以下为未强化的兵器攻击，不含人物与装备。

|职业|凡品|精制基准|上品|名器|传世|
|---|---|---|---|---|---|
|问剑|30|74|150|218|340|
|狂刀|40|100|195|283|440|
|镇岳|25|63|126|181|300|
|幽影|30|74|138|218|360|
|千蛊|30|74|138|218|360|
|弦歌|30|74|138|218|360|

饰品在战斗属性外提供历练银两和经验加成，凡品至传世分别为3%/6%/10%/16%/25%。只读取出发时已佩戴的一个饰品，整数向下取整；正收益加成后仍受经验上限约束。不放大负面损失、不让高人指点凭空产生银两，不影响签到、赌场、寻宝概率；本次拾取的饰品不反向加成本次收益。具体字段为Item.adventure_bonus，和战斗Traits分离。

游戏页面样例由cards/candidate_preview_test.go从候选真实View生成，覆盖六职业初始/满配、切磋、历练、五品寻宝及赌场。寻宝五品并排是美术样例，不是保证掉落。旧三职业历史样张保留文件但不再进入当前预览清单。

## 职业品级覆盖约束

每个职业每档至少一件兵器和一门武技；同品跨职业数量差不超过一项。现存三个旧职业各多一件精制兵器、问剑多一门传世武技，保留既有设计，不靠删除凑齐。后续扩充优先补数量较少的职业，同期内容按六职业检查。通用护具饰品的当前美术图鉴每品各六件，心法每品一门；历史兼容物品不计作新美术覆盖。装备和武学图鉴的覆盖表由候选数据直接统计。

扩充的三条路线分别混合轻灵与稳守、稳守与调息、轻灵与调息的同档预算；整数固定值向下取整，不将两套收益相加。新增饰品沿用同档历练加成。
