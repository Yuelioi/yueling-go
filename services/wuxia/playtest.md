# 月灵江湖小群试玩

## 开始

使用包含迁移020的程序和配套WebUI启动机器人；数据库迁移随程序启动执行。后台「插件开关」启用月灵江湖的全局与试玩群开关，再进入「月灵江湖」选择该群。默认每日3场历练、签到30银两、练武基础50银两即可试玩。单群保存不会影响其他群，恢复全局默认后继续继承全局配置。

后台「群内试玩」可复制按已保存数值生成的说明。将说明发给群友，由两位玩家各发一次「江湖」：自动创建剑客、签到、完成剩余随机历练、收集装备；系统不会自动花费银两练武。首轮同时提供入门指引。也可以直接发送「切磋 @群友」，双方没有侠客时自动创建初始角色后开打；不代领签到或历练奖励，之后发送「江湖」仍可领取完整日常。

## 玩家路线

| 发到群里的指令 | 应看到的结果 |
| --- | --- |
| 江湖 | 首次创建侠客，获得签到及历练奖励；重复发只处理未完成的日常 |
| 我的侠客 | 当前等级、银两、兵刃、已收集武器与每日进度 |
| 江湖转职 | 剑客、刀客、拳师的特点与切换指令 |
| 江湖转职 刀客 | 免费切换，保留等级、银两、武学和收集品；补发该职业初始兵刃 |
| 江湖形象 3 | 外观切为蓝衣拳师，职业与属性不改变；0恢复跟随职业 |
| 江湖武器 剑 | 装备已收集的剑；只保留各类最高阶兵刃 |
| 江湖练武 | 明确扣除人物卡显示的银两，提升一次武学；不足或到等级上限时给出原因 |
| 切磋 @另一位玩家 | 双方缺少角色时自动建角，逐招攻防与气血战报，整场胜率最低10%、最高90%，不扣双方资产 |
| 江湖战报 | 重看自己的最近一次结算快照，标注原结算时间，不重掷、不发奖、不扣款 |
| 江湖榜 | 本群当前战力排行 |

卡片下方是可发送的聊天指令，不是QQ可点击按钮。日常耗尽后仍可免费换职业、换形象和切磋；同一对象切磋间隔30秒。北京时间零点后可重新签到和历练。每个群的角色与资源独立。

「江湖战报」显示原结果；当前状态用「我的侠客」查看。发送失败不会撤销已入库奖励，可以重看战报。单独「江湖签到」和「江湖历练」与一键「江湖」共享当天进度。

## 本地验证

```sh
YUELING_WUXIA_PREVIEW_DIR="$PWD/workshop/wuxia-mvp" ./scripts/test-postgres.sh ./services/wuxia/... ./plugins/wuxia ./services/webui
cd webui
pnpm test
pnpm build
```

测试启动临时PostgreSQL并通过假OneBot传递真实格式消息，不连接QQ群；结束后清理容器。覆盖两名玩家的完整命令流程、模型处理器不接管、跨群与跨机器人战报隔离、重启读取、跨天日常、重复消息、银两流水与后台配置继承。PNG／JPEG发送预览保存在环境变量指定目录。

## 扩展入口

职业、兵刃、事件和场景通过`internal/content/content.json`稳定ID定义；静态模板由`cards/assets/regions.json`映射。新增效果通过独立战斗规则版本演进，既有回执使用保存快照。经济变动统一经过`Execute`事务和流水，避免在插件命令或管理界面直接修改余额。

当前玩法包含职业成长、兵器收集、随机历练和群友切磋；角色使用预制形象。自由捏脸、交易、帮派与多人副本不属于此初版。

## 背包与寻宝

已有侠客可发送「江湖奖池」查看价格与概率，再「江湖寻宝」或「江湖寻宝 5」。默认每抽60银两，无保底。资金不足不扣款、不发奖励。发送「江湖背包」查看所得，「江湖装备 物品名」换装，「江湖学艺 秘籍名」学习；「江湖武学 武学名」选择一门已学武学。重复秘籍保留，换不匹配的兵器时该武学暂停生效。

升级时迁移021保留旧角色成长，将旧兵器回填库存；部署前备份数据库。新增武学、装备和奖池的范围见[内容扩展](extending.md)。
