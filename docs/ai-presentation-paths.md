# AI 相邻链路检查

2026-10-09，接续群聊总结修复，检查普通对话、定时日报、工具结果、知识库、主动发言、长期记忆和对话恢复。

## 修复

- 日报仍强制三个栏目并在没有跟进时填写“无”，缺昵称与提及片段还会暴露账号。现在复用自然总结规则，使用昵称或群友称呼，明确只是最近一段聊天，不暗示全天覆盖。
- 普通对话明确区分对外称呼与内部定位编号。聊天历史仍保留 QQ 动作需要的真实 ID，不破坏撤回、禁言等参数解析。
- 知识库直接问答和工具问答统一使用资料标题与真实来源链接，不再强制输出数据库知识编号；保留仅据检索资料作答的限制。
- 聊天记录、成员查询和天气查询的传输错误不再以成功返回文本拼接底层错误，而是交给统一失败处理；将这些纯查询标为只读，避免失败被当成可能已执行写操作。天气位置查询的服务故障也不再误报城市不存在。
- 长期记忆提取规则进入系统消息，用户、助手与已有记忆采用 JSON 数据边界；明确不得将助手猜测、角色扮演或改变系统行为的指令当成用户事实。
- 主动发言补充聊天资料边界，不服从记录中的指令，不声称执行操作或猜测链接内容。

天气错误分类参照[和风天气错误码](https://dev.qweather.com/docs/resource/error-code/)；HTTP 404 不足以证明城市不存在，因此只将成功查询的空地点结果归为未找到，其他失败保持查询失败。

## 验证与范围

日报模型请求回归先在旧实现触发账号泄漏与空栏目规则失败；记忆提取回归先在旧实现触发规则/数据混杂失败。新增天气错误原文隔离、只读属性和位置服务故障回归。

知识库返回：

> 新人入群后请将群名片改为常用昵称，不要求提交真实姓名。（依据：新人指南）

全仓 PostgreSQL race 回归覆盖现有权限确认、防重复执行、失败结果、会话恢复、图片引用与记忆清除并发行为。本轮未修改这些机制，未发送真实群消息或执行真实群管理动作。上述模型检查只能证明所列虚构案例，不代表所有真实对话没有问题。
