# 群聊总结的内容与口吻

2026-10-09。用户反馈总结只剩话题分类、空的负责人和待办，还输出取样说明及数字来源。

## 根因与改动

旧的直接总结请求强制说明取样限制、标注消息 ID，并把所有内容压在200字内；工具资料也要求决策、负责人和日期。这些要求和普通闲聊总结的目的冲突。模型资料同时包含原始账号、消息 ID 和存储诊断。

现在直接总结与工具总结共用呈现规则：默认讲具体话题、谁说了什么和有内容的接话；明确要待办或结论时再采用相应整理方式。模型只收到昵称与文字，不再收到结构化账号、消息编号和内部取数诊断。内部 Material 仍保留溯源字段。缺失昵称优先采用同一用户在本次资料中的已知昵称，否则称一位群友。聊天正文中的数字不会被盲目删除。

时间范围用自然语言表达，并保留“部分聊天”的限定，不能暗示读过整个时间段。无讨论内容的纯链接可以略过，不猜测图片或视频。总结目标长度允许400—900字，内容少就短说，模型 token 预算保持配置值。
