# 主动发言优先最近消息

2026-10-09。旧实现将20条纯文本拼在一起，没有最新一句标记、发言人或过期时间；生成期间出现新消息也不会取消旧内容，容易继续旧话题。

现在保留五分钟内最多八条消息，单条文字最多400字，分为最新一句、最近两句、其余背景。模型先接最新一句，仅用最近两句理解指代，背景不能因篇幅大而决定回复主题。昵称随消息传入；纯图片等消息只保留“内容未读取”占位，不猜测内容。

新消息（包括非文字和不计热度的消息）取消同群正在生成的回复，不影响其他群。全部上下文过期时清除积累的热度。没有值得接的话或无法理解新话题时，模型输出 NO_REPLY，程序不发送它。生成温度从0.9降到0.6。

三分钟冷却与每天五次限制保留，但生成失败、被取消或静默不占发送次数。开始发送时才预留次数；传输失败可能意味着回执丢失，因此不退还该次数或立即重试。

## 验证

新增“新消息取消过时生成”回归先在旧实现对文字与图片两种情况失败。随后通过生产 Feed 捕获模型请求，验证最新消息/最近两句分区、八条上限、昵称与静默不消耗发送配额；另测过期清理、单条长度和跨群隔离。871项全仓 PostgreSQL race 测试无失败或跳过，最终主动发言定向race与vet通过。

`go run ./cmd/ai-check -proactive-style -model deepseek-flash` 使用生产上下文与请求构建器，只输入虚构聊天：

| --- | --- |

| 老话题下雨，最近两句约鸳鸯锅，最新说“那就这个” | 好嘞，鸳鸯锅走起～ |
